Add a Revizto account
A Revizto app only works for licences in the account it was created in. For each other account that holds a licence:
  1. In Revizto Workspace, switch to that account, then Tools → Manage account info → Developer Portal → Add custom app (Account Owner or Admin).
  2. Redirect URI: . Copy the client ID and the client secret (the secret is shown only once).
  3. Add them below, then click Connect and sign in to Revizto.
⬆ Import Revizto search sets
In Revizto, open Search sets, select the sets or folders you want and click Export. Then pick the .vimsst file(s) here; you can pick several at once. You'll see what's in them before anything is saved. Importing a set again updates it and keeps the columns and formulas you've added here.
